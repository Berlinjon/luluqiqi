# 一年级下册语文小探险

面向一年级下册语文学习的儿童闯关式网页 App。当前版本覆盖 8 个单元、42 个学习关卡，包含识字、笔顺动画、词句练习、朗读示范、奖励屋、错字复习和家长报告。

## 如何打开

在项目根目录启动本地服务后访问：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器打开：

```text
http://127.0.0.1:4173/yuwen-app/index.html
```

## 手机使用

手机和电脑需要在同一网络下。正式给孩子使用时，建议部署到 GitHub Pages、家庭服务器或其他 HTTPS 静态托管服务，再用手机浏览器打开。

支持作为 PWA 添加到桌面：

- iPhone：Safari 打开页面，选择“分享”里的“添加到主屏幕”。
- Android：Chrome 打开页面，选择“安装应用”或“添加到主屏幕”。

## 学习内容

- 识字挑战：听读音、看拼音、选择正确汉字。
- 笔顺动画：使用专业笔顺动画展示书写顺序，并同步朗读“横、竖、撇、捺”等笔画名称。
- 选词填空：围绕本课词句做短练习。
- 朗读示范：播放较慢语速示范音频，并逐句高亮。
- 错字复习：答错的字自动进入复习本。
- 奖励屋：按单元收集徽章，展示星星、连续学习天数和今日宝箱。
- 家长报告：查看完成进度、已学字数、错字建议和本机学习记录。

## 数据与隐私

当前版本不需要登录，不上传儿童学习数据。学习进度保存在浏览器本机的 `localStorage` 中。家长可在“家长”页面清空本机进度。

## 发布说明

这是静态网页应用，核心文件包括：

- `index.html`：主应用。
- `manifest.webmanifest`：桌面安装配置。
- `sw.js`：离线缓存。
- `audio/`：课程朗读、生字、笔画和反馈音频。
- `privacy.html`、`terms.html`：隐私政策和用户协议基础页。

`tools/` 目录是生成音频的维护脚本，不是孩子使用时必须打开的页面。发布到静态托管时可以保留，便于以后补音频；如果只想给孩子用，也可以只发布 `index.html`、`manifest.webmanifest`、`sw.js`、`privacy.html`、`terms.html` 和 `audio/`。
