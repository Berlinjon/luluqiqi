# 语文小探险音频目录

这里放专业普通话音频。页面会优先播放这些音频；如果文件不存在，会自动退回浏览器语音。

## 生字音频

放在 `words/` 目录，文件名使用不带声调的拼音：

- `words/chun.mp3`
- `words/feng.mp3`
- `words/xing.mp3`
- `words/qing.mp3`

## 课文示范

放在 `lessons/` 目录，文件名使用代码里的课文 id：

- `lessons/chunxiaqiudong.mp3`
- `lessons/xingshige.mp3`
- `lessons/xiaoqingwa.mp3`
- `lessons/caizimi.mp3`

## 鼓励语

放在 `feedback/` 目录：

- `feedback/try-again.mp3`
- `feedback/complete.mp3`

## 笔画名称

放在 `strokes/` 目录，文件名使用无声调拼音：

- `strokes/heng.wav`：横
- `strokes/shu.wav`：竖
- `strokes/pie.wav`：撇
- `strokes/na.wav`：捺
- `strokes/dian.wav`：点
- `strokes/piedian.wav`：撇点
- `strokes/hengzhe.wav`：横折

## 推荐来源

优先使用有明确授权的普通话 TTS/配音服务生成，例如云厂商神经网络普通话 TTS 或明确支持商用授权的 TTS API。不要直接复制词典、竞品 App 或未声明授权的网页音频。
