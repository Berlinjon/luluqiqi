# 听句子选图片

这是一个独立的儿童英语听力启蒙网页应用。第一版目标很窄：孩子听一句英文短句，然后从图片里选择对应画面。

## 第一版范围

- 三个孩子独立进度：Lulu / Qiqi / Mimi
- 7 个路线关卡：动物入门、食物入门、入门复习、日常进阶、颜色形状进阶、位置空间进阶、天气自然进阶
- 每关 15 句，共 105 道练习；其中入门复习复用前两关素材做巩固
- 88 个不重复句子全部使用本地英文音频，当前语音为 Voicebox / Kokoro 82M / af_alloy
- L1 关卡使用二选一降低挫败感，L2 关卡使用四选一训练精细辨析
- 学习页顶部支持 Level、英文提示、中文提示、语速、题号和星星分
- 所有题目选项图已接入 GPT-Image2 风格库生成题图，新增主题已补专属语义图片
- 本机保存通关进度、星星和错题记录
- 家长端查看每个孩子完成度、星星数、错题数和最近错题
- 支持添加到主屏幕和离线打开

## 入口

直接打开：

`./index.html`

## 图片资产

当前版本的题目选项图已全部替换为真实插画，位于 `assets/illustrations/generated/`，使用 `gpt-image-2-style-library` 的 `illustration-art-style` 模板提示词生成。

88 条主线音频位于 `audio/sentences/`。应用会优先播放本地音频，缺失时回退到浏览器朗读。

语音批量生成脚本：

`tools/generate-voicebox-af-alloy-audio.cjs`

默认只生成缺失音频；如需强制重生成全部音频，可追加 `--force`。
