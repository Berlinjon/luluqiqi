# 干扰项设计规则

本规则用于维护“听句子选图片”的题库质量。目标不是让干扰项越难越好，而是让孩子能通过听懂英文句子的关键语义做出选择。

## 核心原则

1. 正确图必须覆盖句子的核心语义：主角、动作、物体、颜色、位置或天气。
2. 干扰图应尽量只改变一个关键点，例如动物、动作、颜色、数量、位置或天气。
3. 入门关卡可以使用差异明显的二选一，降低挫败感。
4. 进阶关卡的四选一至少应包含一到两个“近干扰项”，避免全部随机凑图。
5. 不使用危险、负面、卫生混乱或世界逻辑明显错误的场景作为低龄儿童练习题。

## 合格干扰项示例

- `The dog is running.`：干扰项可以是 `cat_sleep`、`bird_fly`，改变动物或动作。
- `The bag is beside the chair.`：干扰项可以是 `bag_near_chair`、`bag_next_ball`，改变位置或参照物。
- `The sun is hot.`：干扰项可以是 `sun_bright_weather`、`snow_cold`，改变天气感受。

## 需要审查的情况

- 四个选项里有重复图片。
- 正确图片不在选项里。
- 干扰项和正确项完全没有共同语义，例如颜色题混入毫不相关的日常动作图。
- 正确图 key 和英文句子没有明显语义重合。
- 句子、中文提示或图片 key 出现 fight、cry、hurt、sock-in-food、unsafe playground 等不适合低龄儿童的内容。

## 自动审计

运行：

```bash
node english-listening-app/tools/audit-distractors.mjs
```

脚本会输出结构性错误和质量提醒。结构性错误需要优先修复；质量提醒用于人工复核，不会默认阻断构建。
